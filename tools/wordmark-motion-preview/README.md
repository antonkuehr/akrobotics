# Editable navbar wordmark

Open [motion-preview.html](motion-preview.html) locally, or visit it through the local preview server. The editor loads the **installed** website geometry, settings, engine and CSS; it has no public navigation link.

- Motion: edit [wordmark-settings.js](../../assets/js/wordmark-settings.js), or download revised settings from the editor and replace that file.
- Geometry: edit the SVGs in `editable-shapes/`, preserving the path IDs and font-space group, then run from the repository root:

  ```sh
  python3 tools/wordmark-motion-preview/tools/import-shape.py wide tools/wordmark-motion-preview/editable-shapes/wide.svg
  ```

  The importer updates `editable-shapes/shapes.json` and the **installed** [wordmark-shapes.js](../../assets/js/wordmark-shapes.js) directly. No duplicate runtime copy needs synchronising.

Advance the changed asset's cache query in all eight shared-navbar pages and the editor. Changes to the resting geometry also require updating the static wordmark, inline initial paths and favicon assets; the importer does not regenerate them.

Editable source artwork and the importer remain here. Original ZIP uploads, duplicate markup and preparation notes are stored locally under the ignored `.local-notes/repository-cleanup-2026-10-19/` archive; they are not website assets. The paths above describe the installed integration.

The website engine watches ancestor visibility so its introduction waits for the homepage navbar to finish appearing, then pauses for `intro.delayMs` (900 ms by default). The same pause applies after reload and each scroll reveal; hiding or stopping a logo cancels the pending start. The navbar plays one cycle on each appearance, then repeats every 10 seconds. The hero plays two cycles initially, one cycle when it reappears after scrolling away, and two cycles at each recurring 30–45 second interval. Recurring intervals are measured between cycle starts; the first idle interval begins after the introduction finishes. Reloading or clicking the navbar home link resets both logos. Hidden logos and tabs stop scheduling, and reduced motion keeps the normal ü static. Motion timing and geometry remain editable in the installed settings files.

Both the hero and navbar start and rest on the normal ü. Each animation flows through **normal ü → smiley → wide/handshake → normal ü**, returning directly from the handshake to normal without another smiley phase. The inline SVGs use the normal ü as their initial, no-JavaScript artwork as well.

All three transitions synchronize the dots and stems: they share start time, duration and easing, without stagger or spring bounce. The downward transition lasts 1450 ms, the outward transition 1150 ms and the inward-curved return 1950 ms before applying `tempo`. The return uses an easing curve with zero velocity and acceleration at both ends. Tune `sequence[].bodyMs` and `sequence[].easing`; synchronized steps use `bodyMs` for every part. The optional spring, lag and vertical arc settings apply only when a step has `synchronized: false`.

The return to normal uses a shallow 25-unit inward bow; tune `dots.returnInwardUnits`. With the installed artwork, the dots retain at least their normal resting gap throughout the return and keep travelling towards their final positions without turning back. The switchable experiment retains one right-eye wink while smiling: 450 ms before the blink, 300 ms to close and reopen, then 850 ms before moving on (all before applying `tempo`). Tune `experiments.wink.beforeMs`, `durationMs` and `afterMs`; the pose hold always accommodates those three timings. Immediately after the dots finish moving outwards, the lower central “hands” curve makes one slow **up → down → centre** gesture over 1300 ms, without bounce or repeats; the heads stay still. A 300 ms pause follows the completed handshake before the return begins (before applying `tempo`). The hands move by up to 50 font units for a subtler gesture. The downward reach is halved with `experiments.handshake.downwardScale: 0.5`, while upward travel and the 1300 ms timing remain unchanged. The up and settling strokes each use a quarter of the gesture time and the downward stroke uses half, with smooth turnarounds. Tune `experiments.handshake.amplitudeUnits` for overall travel. Use **Wink + handshake experiment** in the editor, or set `experiments.enabled` to `false`. The editor exposes overall speed, handshake duration, handshake travel and return duration, and exports those settings. The editor preserves the pause after the handshake when its duration is adjusted. Keep the wide pose hold longer than the handshake duration to tune that pause directly. Eye, closed-eye scale and shake amplitude remain editable in settings. Reduced motion and cancellation restore the normal ü immediately.
