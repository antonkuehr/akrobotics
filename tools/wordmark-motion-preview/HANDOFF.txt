3. DEFAULT MOTION AND SCHEDULING

The canonical state order is original -> smiley -> wide -> smiley. All other
letters stay fixed. Original uses the real font glyph. Smiley and wide use the
actual dot curves and placements extracted from the user's PDFs. Wide changes
the dot spacing while keeping the smiley's lower outline unchanged.

The body uses a monotonic smooth ease. Each dot uses a damped spring response,
a slight independent start delay and a small vertical arc. Different transitions
have different durations. No circle is stretched as an animation effect.
The original/font dot outline changes subtly into the PDF's actual circle outline.

Default body transitions: 900–1200 ms; dot flights:1450–1800 ms plus 70/155 ms delay.
This is deliberately slower than the earlier 380 ms preview. Holds give each
pose time to read. Two complete intro cycles take approximately 21 seconds at
normal speed, including the holds. The logo then rests on the smiley.

Automatic introduction waits for the SVG and its wrapper to be visible. Completed
intro cycles are remembered in sessionStorage. If a cycle is interrupted by
hiding the logo, it is not counted as completed. It resumes as a fresh cycle on
visibility. The engine never plays out of sight behind the homepage hero.
After the intro, an idle cycle is scheduled at a random interval of 60–90 seconds.
Timers are cancelled and the smiley restored when the tab or logo is hidden.
The idle countdown starts afresh when visible, so there is no catch-up burst.
Reduced-motion preference changes cancel motion immediately and keep a static
smiley. A manual pose selection in the editor changes instantly in reduced mode.
There is no permanent requestAnimationFrame loop while resting.

4. EDITING THE MOTION AFTER IMPLEMENTATION

Edit assets/js/wordmark-settings.js directly on the website, then advance its
version query. Settings are plain readable JavaScript:
- tempo: higher is faster; 0.75 is slower than 1.
- dots.damping: lower gives more overshoot; keep 0.55–1. Default 0.7 is gentle.
- dots.frequency: controls acceleration/settling within the allotted dot duration.
- dots.lagMs: independent left/right start delay.
- dots.arcUnits: small upward travel arc in font units (20 units is 0.4 px at
  20 px font-equivalent navbar size; magnified previews show it more clearly).
- sequence[].bodyMs / dotsMs / holdMs: edit each phase independently.
- intro.cycles / oncePerSession / storageKey and idle.enabled / minMs / maxMs:
  control repetition. Change the storage key when deliberately resetting the intro.

5. EDITING THE ARTWORK AFTER IMPLEMENTATION

assets/js/wordmark-shapes.js is the runtime geometry. Each pose has three named
path command lists: body, leftDot and rightDot. Coordinates are in a 1000-unit
font space, with y upwards. Lower outline and original wordmark spacing are fixed.

editable-shapes/original.svg, smiley.svg and wide.svg are editable source artwork.
Keep the font-space group and the three path IDs. Move points or individual dot
paths. Do not alter the display transform on font-space. To import an edit:
  python3 tools/import-shape.py wide editable-shapes/wide.svg
The tool writes both editable-shapes/shapes.json and assets/wordmark-shapes.js.
It supports individual path transforms and ordinary line/quadratic/cubic paths,
but rejects incompatible command counts or arc paths with an explanation. Keep
the existing path points when editing; do not simplify or replace dots with new
ellipse primitives unless the implementing AI normalises all three poses again.

Editing an SVG alone does not update the site automatically. Run the importer,
copy/synchronise the generated JS into the installed assets/js location, advance
its cache version and reload. If editing the resting smiley, update the static
wordmark.svg, the inline SVG's initial paths and favicon variants too; animation source edits do not regenerate
those static assets automatically. Keep that distinction explicit.

For edits during a browser session:
  const svg = document.querySelector('.site-header svg[data-ak-wordmark]');
  const logo = AKWordmark.get(svg);
  logo.setOptions({ tempo: 0.8, dots: { damping: 0.72 } });
  logo.setShape('wide');       // manual selection pauses automatic scheduling
  logo.playCycle();            // one sequence
  logo.playIntro();            // two cycles, independent of stored intro count
  logo.pause();                // cancel current motion, return to smiley
  logo.resume();               // resume visibility-aware production scheduling
  logo.setShapeData('wide', newCompatiblePose);
  logo.getState();
  logo.destroy();              // disconnect all observers, listeners and timers
Manual pose/play commands pause automatic scheduling until logo.resume() is called.
These calls are optional development tools, not a visitor-facing UI.
